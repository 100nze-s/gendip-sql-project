# 🌍 GenDip Data Analysis (1968 - 2021)

Analisi SQL e esplorazione statistica della rappresentanza di genere nella diplomazia internazionale basata sul dataset **GenDip (Gender and Diplomatic Representation)** della University of Gothenburg.

---

## 📂 Struttura della Repository

La repository è organizzata come segue:
- `queries.sql`: File contenente tutte le query SQL eseguite su PostgreSQL (pgAdmin), strutturate per fasi e corredate da commenti espliciti su obiettivo e risultato atteso.
- `data/`: Contiene la sorgente dei dati (`.csv`) e la documentazione ufficiale di riferimento (`.pdf`).
- `presentation/`: Raccoglie le slide finali del progetto in formato PDF.

---

## 📊 Informazioni sul Dataset
Il dataset traccia l'evoluzione delle nomine diplomatiche a livello globale, copre più di 200 Paesi e 10 anni specifici tra il 1968 e il 2021, integrando caratteristiche istituzionali e indicatori politici avanzati (come la presenza femminile nei parlamenti e l'adozione di politiche estere femministe - FFP).
- **Sorgente ufficiale:** [GenDip Project](https://www.gu.se)
- **Codebook di riferimento:** Consultabile nella cartella `data/GenDip_Dataset_Codebook_vJune23_2023-06-13.pdf`
